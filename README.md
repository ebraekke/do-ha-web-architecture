# do-ha-web-architecture

## Use

```
tofu plan --out=dohaweb.tfplan --var-file=config/fra1.tfvars
```

## Overview 

DigitalOcean implementation  of a highly available web architecture.

Inspired by and partially copied from [work](https://github.com/do-community/terraform-sample-digitalocean-architectures) by Mason Egger. 

The bastion approach is inspired [this post](https://annaken.github.io/building-a-secure-bastion/) by Anna Kennedy.
